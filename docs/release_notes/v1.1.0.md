# v1.1.0

A major feature release introducing multi-model quota breakdown support across Cursor, Copilot, and Codex, resilient numeric JSON schema parsing, automated MSIX Store packaging, and enhanced PowerToys Dock integration.

### 🧠 Multi-Model & Provider Expansions
- **Cursor Multi-Model & Usage-Based Pricing**: expanded Cursor quota parsing to handle multi-model usage pools (Claude 3.5 Sonnet, GPT-4o, etc.), fast requests balance, and on-demand usage-based pricing tracking ([#4](https://github.com/esoltys/PowerQuota/issues/4), [#8](https://github.com/esoltys/PowerQuota/pull/8)).
- **GitHub Copilot Multi-Model Snapshots**: support dynamic request headers and multi-model quota breakdown snapshots in Copilot provider responses ([#2](https://github.com/esoltys/PowerQuota/issues/2), [#7](https://github.com/esoltys/PowerQuota/pull/7)).
- **Codex / ChatGPT Schema Resilience**: enhanced schema resilience for nested window models, token rate limits, and multi-model sliding quota structures ([#1](https://github.com/esoltys/PowerQuota/issues/1), [#6](https://github.com/esoltys/PowerQuota/pull/6)).
- **Kimi & Minimax Dual-Type Numeric Parsing**: added custom JSON converters to transparently parse both numeric and string values for quota limits, remaining balances, and reset timestamps across Moonshot Kimi and Minimax APIs ([#3](https://github.com/esoltys/PowerQuota/issues/3), [#5](https://github.com/esoltys/PowerQuota/pull/5)).

### 📦 Packaging & Desktop Integration
- **Microsoft Store MSIX Packaging Pipeline**: introduced `build-msix.ps1` supporting x64, arm64, and multi-architecture `.msixbundle` generation with automated user environment identity resolution and developer certificate signing.
- **High-DPI Visual Assets**: generated comprehensive visual assets across 100%, 125%, 150%, 200%, and 400% scaling for Wide Tiles (310x150), Large Tiles (310x310), Small Tiles (71x71), App Logos, and Splash Screens.
- **Pinnable Individual Window Commands**: surfaced individual provider quota windows directly as top-level CommandItems in PowerToys Command Palette for individual search and Dock pinning.
- **Developer Helper Scripts**: added `register.ps1` and `reload.ps1` for rapid local testing, automatic clean unregistration, and live Command Palette reloading.
