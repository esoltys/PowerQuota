# v1.0.0

The initial release of PowerQuota — an AI coding quota monitor designed specifically for Windows PowerToys Command Palette & Dock.

### 🌟 Features
- **Multi-Provider AI Quota Tracking**: real-time quota, rate limit, and credit tracking for 7 major AI coding providers:
  - Anthropic Claude (Session & Weekly token windows, subscription plan detection)
  - OpenAI Codex / ChatGPT (5-hour session & weekly rate limits)
  - Cursor (Fast requests & model allowances)
  - Google Gemini (Rate limits, token quotas, and credit balances)
  - GitHub Copilot (Subscription status & model allowances)
  - Moonshot Kimi (API token quotas & balance)
  - Minimax (API token allowances & usage)
- **PowerToys Command Palette & Dock Integration**:
  - Live progress bars and percentage bands rendered directly on the Windows desktop Dock.
  - Interactive Command Palette pages for overview, provider details, and quick configuration.
  - Configurable Dock band styles (`PercentageOnly`, `BarsOnly`, `LogoAndPercentage`).
- **Zero-Friction Local Authentication**:
  - Automatic CLI credential discovery (scans for Claude Code CLI and local development sessions).
  - Secure credential storage backed by the native Windows Credential Manager / Vault.
- **Hierarchical Settings**: customize refresh intervals, default Dock display modes, and manage accounts with live in-place previews.
- **Modern .NET 10 Foundation**: built on modern .NET 10 with Windows App SDK COM server activation for near-zero startup overhead.
