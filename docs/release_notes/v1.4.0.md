# PowerQuota v1.4.0 Release Notes

## Antigravity Google Gemini Integration & Independent Pinning

### Summary
PowerQuota v1.4.0 replaces the legacy Gemini Code Assist integration with the modern Antigravity Quota system (`cloudcode-pa.googleapis.com`), enabling separate rate-limit tracking and independent taskbar/dock pinning for **Gemini Models** and **Claude/GPT Models**.

---

### Key Features & Improvements
- **Automatic Antigravity Session Detection**: Automatically scans Windows Credential Manager (`gemini:antigravity`) and local IDE storage (`state.vscdb`) for active OAuth sessions.
- **Seamless OAuth Token Auto-Refresh**: Proactively and reactively refreshes expired Google OAuth access tokens against `oauth2.googleapis.com`.
- **Modern Cloud Code API**: Migrated to `v1internal:loadCodeAssist` and `v1internal:retrieveUserQuotaSummary`.
- **Independent Taskbar & Dock Pinning**: Rate limit metrics are separated into distinct windows:
  - `Gemini (5h)`: 5-Hour Limit Remaining
  - `Gemini (Weekly)`: Weekly Limit Remaining
  - `Claude/GPT (5h)`: 5-Hour Limit Remaining
  - `Claude/GPT (Weekly)`: Weekly Limit Remaining
  Each window is exposed as an individual Dock item so users can pin only Gemini stats without pinning 3P model stats.
- **Updated Guidance**: Replaced legacy "run 'gemini' in terminal" prompts with modern Antigravity session guidance.
