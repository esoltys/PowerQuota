# PowerQuota v1.13.0 Release Notes

## .NET 11

### Summary
PowerQuota v1.13.0 moves the entire solution from .NET 10 to .NET 11. There are no user-facing feature changes in this release.

---

### Key Features & Improvements
- **Upgraded to .NET 11**: `PowerQuota.Core`, `PowerQuota.CommandPalette` and the test project now target `net11.0-windows10.0.26100.0`, and the release workflow builds with the .NET 11 SDK.
- **Dependency updates**: `Microsoft.Data.Sqlite`, `System.Security.Cryptography.ProtectedData` and `System.Drawing.Common` are updated to 11.0.0, and the pinned `SQLitePCLRaw.bundle_e_sqlite3` is updated to 3.0.5 as required by `Microsoft.Data.Sqlite` 11.
- **Developer note**: Building from source now requires the .NET 11 SDK. Local publish output paths (`reload.ps1`, README) use the `net11.0-windows10.0.26100.0` folder.
