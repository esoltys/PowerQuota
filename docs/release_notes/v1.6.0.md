# PowerQuota v1.6.0 Release Notes

## Reliable In-Place Updates

### Summary
PowerQuota v1.6.0 fixes a bug where the Command Palette extension kept running its old code after an update installed, and cleans up project board automation.

---

### Key Features & Improvements
- **Fixed stale extension after update**: MSIX updates (Store or sideload) swap files on disk and bump the registered package version, but the already-running Command Palette COM server process kept executing the old assembly until something else killed it — so an update could report success while the live extension stayed on the previous version. The extension now watches for its own package update via `PackageCatalog` and exits the host process as soon as the swap completes, so PowerToys relaunches it against the new files. (#40, #41)
- **CI / Project Automation**: Removed the `add-to-project` Actions workflow, which silently failed on every PR/issue because `GITHUB_TOKEN` can never authorize adding items to a user-owned Projects v2 board. Replaced by the project's built-in "Auto-add to project" automation, which needs no PAT/secret. (#42, #43)
