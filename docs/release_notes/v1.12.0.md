# PowerQuota v1.12.0 Release Notes

## Claude OAuth Sign-In

### Summary
PowerQuota v1.12.0 introduces independent browser-based OAuth sign-in (PKCE) for Claude accounts, eliminating reliance on Claude Code CLI credentials or Claude Desktop usage cache. Tokens are stored securely in Windows Credential Vault and refreshed automatically without interfering with CLI sessions.

---

### Key Features & Improvements
- **Dedicated Claude OAuth sign-in flow**: Claude accounts now authenticate directly via PowerQuota's own OAuth flow using PKCE and a local loopback callback. Refresh tokens are kept in Windows Credential Vault and managed independently by PowerQuota, permanently resolving token rotation conflicts with Claude Code CLI and stale tokens when the CLI is inactive. (#78, #79)
- **Interactive login in Command Palette**: Added a seamless sign-in experience to Command Palette. Adding a Claude account or selecting an account that requires login opens the sign-in page in your default browser. A "Log in Again" context menu item makes switching Claude accounts straightforward. (#79)
- **Architecture and privacy documentation**: Documented PowerQuota's provider adapter architecture and direct-to-provider zero-telemetry privacy invariant in `AGENTS.md`. (#80)
