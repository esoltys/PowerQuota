# PowerQuota v1.11.0 Release Notes

## Claude Extra Usage Minor Units Fix

### Summary
PowerQuota v1.11.0 fixes a bug where Claude extra usage (usage credits) displayed inflated by 100x because the underlying API values are provided in minor currency units (cents).

---

### Key Features & Improvements
- **Corrected Claude extra usage credit and limit values**: Anthropic's usage endpoint returns `extra_usage.used_credits` and `extra_usage.monthly_limit` in minor currency units (cents, e.g. `277` for $2.77 CAD). PowerQuota now divides these by `100.0` so that extra usage amounts and configured limits reflect dollar values accurately (e.g. `2.77 CAD extra` instead of `277.00 CAD extra`). (#75, #76)
