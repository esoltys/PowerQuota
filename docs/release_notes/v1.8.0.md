# PowerQuota v1.8.0 Release Notes

## Antigravity Daily Sync & Preserved Claude Sessions

### Summary
PowerQuota v1.8.0 resolves Claude Code CLI session invalidation caused by background OAuth token refresh, updates Gemini quota syncing to use the Antigravity daily endpoint for active session tracking, and adds a dedicated sideload uninstallation script.

---

### Key Features & Improvements
- **Preserved Claude CLI session during background polling**: Previously, when PowerQuota proactively refreshed Claude Code's OAuth tokens, Anthropic's OAuth Refresh Token Rotation (RTR) invalidated the CLI's single-use refresh token, causing users to be logged out of Claude Code CLI. PowerQuota now uses Claude Code's credentials while valid without consuming its single-use refresh token, and re-reads credentials from disk when Claude Code refreshes them. (#52, #57)
- **Antigravity Gemini quota real-time sync**: Updated Gemini quota tracking to query `daily-cloudcode-pa.googleapis.com` as the primary endpoint to reflect the active Antigravity session quota, with automatic fallback to `cloudcode-pa.googleapis.com`. Also adds dynamic token resynchronization from Windows Credential Manager on 401 responses, re-scanning, and resets the `RetryAfter` backoff on manual refresh. (#55, #56)
- **Sideload uninstallation script**: Added `uninstall-powerquota.ps1` to cleanly remove sideloaded developer AppX packages, prune stale Command Palette provider caches, and clear orphaned dock bands without touching Microsoft Store installations. (#53, #54)
