# PowerQuota v1.5.0 Release Notes

## Gemini Quota Alignment & UI Consistency

### Summary
PowerQuota v1.5.0 standardizes Google Gemini quota formatting to match Claude's standard presentation style in the Command Palette and Windows Taskbar / Dock band cards, resolves third-party model filtering across details views, and adds automated project board triage.

---

### Key Features & Improvements
- **Standardized Quota Labels**:
  - Gemini 5-hour window is now labeled as `Session` with description `5-hour session window` (rendering subtitle as `Session • 5-hour session window` or `Session resets in...`).
  - Gemini weekly window is now labeled as `Weekly` with description `Weekly quota` (rendering subtitle as `Weekly • Weekly quota` or `Weekly resets in...`).
  - Third-party models are labeled as `Claude/GPT (Session)` and `Claude/GPT (Weekly)`.
- **Third-Party Model Filtering**:
  - Provider details page now strictly respects the `GeminiIncludeThirdPartyModels` setting, hiding Claude and GPT cards when 3P models are disabled.
  - Robust bucket identification via `bucketId` (`3p-weekly`, `3p-5h`, `gemini-5h`, `gemini-weekly`).
- **Command Palette & Dock Stability**:
  - Exact title matching in `GetCommandItem` prevents stale dock IDs from matching unrelated commands.
  - Automatic pruning of orphaned dock band IDs during registration and reload.
- **CI / Project Automation**:
  - Added automated GitHub Actions workflow to auto-triage newly opened issues and pull requests to the project board with least-privilege permissions.
- **Dock Stability**:
  - Fixed the PowerToys Dock and Command Palette top-level list flickering/reloading repeatedly during each quota refresh cycle. `QuotaRefreshService` now notifies state changes once per refresh cycle instead of once per provider, eliminating the duplicate `StateChanged` event storm (up to 8 redundant notifications per cycle).
