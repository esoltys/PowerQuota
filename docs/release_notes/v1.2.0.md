# v1.2.0

A targeted reliability update resolving pinned Dock card persistence and Command Palette ID lookup stability.

### 🎛️ Dock & Command Palette Integration
- **Persistent Pinned Dock Cards**: assigned deterministic, stable IDs to all individual quota cards and provider bands (`dock-{pid}-{accountId}-{window}`) so cards stay pinned across quota updates, automatic refreshes, and PowerToys restarts ([#9](https://github.com/esoltys/PowerQuota/issues/9), [#10](https://github.com/esoltys/PowerQuota/pull/10)).
- **Enhanced Command Resolution**: updated `GetCommandItem` lookup in `PowerQuotaCommandProvider` to resolve both top-level search commands and active Dock band cards seamlessly by unique ID ([#9](https://github.com/esoltys/PowerQuota/issues/9), [#10](https://github.com/esoltys/PowerQuota/pull/10)).
- **Automated Regression Tests**: added automated test coverage validating stable command ID formatting and lookup across all providers and active quota windows ([#10](https://github.com/esoltys/PowerQuota/pull/10)).
