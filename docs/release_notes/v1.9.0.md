# PowerQuota v1.9.0 Release Notes

## Claude Desktop Fallback

### Summary
PowerQuota v1.9.0 stops nagging Claude Desktop-only users to log into the Claude Code CLI, by reading the usage data Claude Desktop already caches on disk when no CLI session or OAuth token is available.

---

### Key Features & Improvements
- **Claude Desktop usage cache fallback**: Previously, `ClaudeProvider` only ever read a Claude Code CLI session from disk or a manually configured OAuth token — anyone who used Claude Desktop but rarely touched the CLI was told to run `claude` in a terminal to log in, even though Desktop already had an active session. PowerQuota now falls back to Claude Desktop's own `plan-usage-history.json` cache (five-hour/seven-day utilization samples Desktop writes during normal use, no token or network call required) whenever no CLI session and no OAuth token are available. Each fallback window is marked with a note that a real login would provide live data and reset times, so the degraded state stays visible rather than being silently masked; PowerQuota still requires login exactly as before when neither source is available.
